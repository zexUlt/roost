# 12. Доверие

- Плагины без песочницы. Плагин видит всё, что отдаёт API, включая транскрипты, и может печатать в сессии. Ставить только доверенные.
- Нативный плагин работает в процессе окна с его правами и памятью. Чтобы `.app` с hardened runtime грузил библиотеки, подписанные другим Team ID, нужен entitlement `com.apple.security.cs.disable-library-validation`: тогда окно грузит библиотеку с любой подписью, но неподписанную на arm64 не грузит и атрибут `com.apple.quarantine` не снимает. Не проверено, проверяется в M8.
- Сокет `roostd` — только для своего пользователя: каталог 0700, на Linux проверка `SO_PEERCRED`, на macOS — `getpeereid`.
- Хуки агентов и любые правки чужих конфигов — только по явному согласию в UI.
