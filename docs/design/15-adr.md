# 15. ADR

Короткие записи вида Контекст / Решение / Альтернативы / Последствия — чтобы каждое решение ревьюилось отдельно и имело историю.

| # | Решение |
|---|---|
| 001 | Окно на Qt Quick и C++ |
| 002 | Отдельный демон `roostd` на QtCore; окно без невосстановимого состояния |
| 003 | libghostty-vt как эмулятор терминала, а не свой парсер и не xterm.js |
| 004 | Тёплый пул attach в демоне и снимок терминала при открытии сессии |
| 005 | Плагин — каталог из QML и необязательного бэкенд-процесса; нативный код — через SDK (ADR 013) |
| 006 | Без песочницы плагинов в v1 |
| 007 | Связи панелей — привязки свойств QML, хранятся в JSON раскладки |
| 008 | Один сокет: JSON-RPC 2.0 плюс бинарные кадры PTY, без base64 |
| 009 | Встроенные фичи на публичном API, без привилегированных путей |
| 010 | Только модули Qt под LGPLv3, динамическая линковка, без AOT QML в v1 |
| 011 | C++ в стиле zet, а C++-слой для QML (`src/qml_api/`) и сам QML — в стиле QML |
| 012 | Хуки агентов ставятся только по явному согласию пользователя |
| 013 | Нативные плагины через C ABI, свои QML-типы — QML-модулем плагина |
| 014 | Хоткеи пользователя — `keymap.json`, читает `roostd`; модификаторы по физическим клавишам |
