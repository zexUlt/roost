# ADR 014: хоткеи пользователя — `keymap.json`, читает `roostd`

**Контекст.** Плагины назначают клавиши вкладами в манифесте (§5); пользователю нужно переназначать и снимать их без правки чужих манифестов. Клавиши живут в двух контекстах: буквы — в списке, сочетания с модификатором — везде, включая терминал, где непойманное нажатие уходит в PTY. Из прежнего TUI переезжает работа букв на русской раскладке.

**Решение.** Файл `keymap.json` в каталоге состояния, массив записей `{key?, mac?, command, args?, when?}`. Его читает и сводит с вкладами `roostd`, окно получает итоговую таблицу по `keymap.get` и `keymap.changed`. Модификаторы называют физические клавиши (`Cmd` только на macOS, `Ctrl`, `Alt`, `Shift`). Буква сопоставляется по символу латинской раскладки, на нелатинской — по положению на US. Таблица ключуется парой (клавиша, `when`); клавиша без модификатора в терминале и полях ввода не срабатывает. Подробности — §16.

**Альтернативы.**

| Вариант | Почему нет |
|---|---|
| `keymap.toml` | новая зависимость ради комментариев; остальное состояние уже в JSON |
| свой строчный формат вида `Cmd+N = claude.newSession` | второй разборщик и второй формат рядом с JSON; `args` в строку не ложатся |
| JSON с комментариями (JSONC) | `QJsonDocument` его не читает: нужен свой разборщик или зависимость. Можно добавить позже, старые файлы останутся корректными |
| хоткеи в `Roost.store` плагина | файл пишет демон: ручная правка затрётся следующей записью |
| файл читает окно | второй владелец каталога состояния; конфликты с вкладами уже считает реестр в демоне, их пришлось бы считать дважды |
| запись клавиш через `QKeySequence` | на macOS `Ctrl` в Qt — это ⌘; текст клавиши зависит от раскладки |
| буквы всегда по физическому положению на US | `Cmd+Z` на Dvorak и AZERTY уезжает с клавиши Z |
| буквы всегда по символу раскладки | на русской раскладке буквы списка перестают работать, а в прежнем TUI они работают |
| `Cmd` на Linux значит Super | Super занят рабочим столом; запись с ним молча не срабатывала бы |
| последовательности `Cmd+K Cmd+S` | ожидание второго нажатия задерживает первое; в прежнем TUI их нет |

**Последствия.** В протоколе появляются `keymap.get` и `keymap.changed`; id плагина `keymap` зарезервирован. Вклады получают ключи `mac` и `when`; неразборная клавиша во вкладе больше не отвергает манифест. Исполнение команд без бэкенда — открытый вопрос (§14). Нужно сопоставление по нативному скан-коду клавиши, которого в `MapQtKey` пока нет. Комментариев в файле нет.
