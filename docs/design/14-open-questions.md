# 14. Открытые вопросы

| Вопрос | Что решит |
|---|---|
| Linux — это рабочий стол или dev-VM по ssh | от этого зависит, нужен ли удалённый `roostd` до M7 |
| что входит в Qt Qml Compiler (GPL) и задевает ли это `qmlcachegen` | можно ли включать AOT для QML |
| грузит ли подписанный `.app` чужую библиотеку и не появляется ли у QML-модуля плагина вторая копия Qt | смоук-тест в M7 (§12) |
| JSON или бинарный формат данных в SDK | замер `host->call` в GUI-потоке в M5 |
| хватит ли одного потока ввода-вывода на окно | замер в M3: 10 терминалов по 1 МБ/с |
| как мерить задержку нажатия на macOS | первоисточника с методикой нет (prior-art §5.3) |
| лицензия roost | Apache-2.0 предположена по образцу zet, не подтверждена |
