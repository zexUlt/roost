# 8. Состояние и миграция

- `roostd` хранит состояние в JSON под `~/.config/roost/`, отдельное пространство имён на плагин. Запись атомарная: временный файл и `rename`.
- Каталог: `ROOST_CONFIG`, иначе `$XDG_CONFIG_HOME/roost`, иначе `~/.config/roost`. Без `HOME` и без двух переменных выше демон не стартует, а не пишет в корень. Созданный демоном каталог закрыт правами 0700. Файл плагина — `<id>.json` с правами 0600. В id только строчные латинские буквы, цифры, `.`, `_` и `-`, первым символом буква или цифра: на нечувствительной к регистру ФС macOS `Claude` и `claude` иначе стали бы одним файлом. Файл, который не разбирается, — ошибка, а не пустой документ.
- `keymap.json` в том же каталоге — файл хоткеев пользователя (§16). Демон его читает, но не пишет; неразборный `keymap.json` — исключение из правила выше: действует прежняя таблица клавиш. Id плагина `keymap` зарезервирован, чтобы файл состояния плагина с ним не совпал.
- Состояние cc-fleet (`~/.config/cc-fleet/*.json`) roost не импортирует: пользователь один, и категории с именами он переносит руками один раз. Совместимость форматов не держится.
- Из cc-fleet переезжает логика: категории, пины, архив, имена, цвета, непрочитанные, переходы и тексты уведомлений, поиск PR по worktree, keep-awake. Тесты cc-fleet (`test_pins`, `test_tree`, `test_fold_cursor`, `test_notify`, `test_pulls`, `test_awake`, `test_subagents`, `test_launched`, `test_title`) переносятся в Qt Test случай за случаем.

## Документ `sessions`

Плагин `sessions` хранит список в документе `sessions` (`<ROOST_CONFIG>/sessions.json`), версия 1. Ключ сессии — `<agent>/<id>`: id плагина не содержит `/`, первая косая черта делит ключ однозначно.

```json
{
  "version": 1,
  "categories": { "claude/bg-0a1b": "work" },
  "names": { "claude/bg-0a1b": "имя" },
  "archived": ["claude/bg-1b2c"],
  "colors": { "work": 0 },
  "pinned": ["work", ""],
  "folded": [""],
  "unread": ["claude/bg-2c3d"],
  "states": { "claude/bg-0a1b": "working" },
  "view": { "query": "", "tab": "all", "archive": false, "compact": false, "opened": "claude/bg-0a1b" }
}
```

- Категория `""` — «Uncategorized». `colors` — индекс палитры 0–7: категории получают цвета по очереди, после восьмой повторяется наименее используемый; у `""` цвета нет. `pinned` хранит порядок закрепления.
- `version` не больше 1 или нет — документ читается и пишется. Больше 1 — список показывается, но не пишется: старый roost не затирает новый документ.
- Разбор прощает по записи: запись неверного типа или с ключом не вида `agent/id` отбрасывается, остальные читаются. Раздел неверного типа считается пустым.
- Записи не чистятся сами: исчезновение сессии из `sessions.list` может быть временным. Запись убирает только `Forget(key)` после удаления сессии.
- Непрочитанное считается по смене состояния: сессия непрочитана, если её состояние изменилось на любое, кроме `working`, или она появилась в таком состоянии, и она не открыта. Открытая сессия не бывает непрочитанной, открытие её прочитывает. `states` хранит последние виденные состояния, поэтому сессия, закончившая работу без окна, при загрузке непрочитана. Документ без `states` — первый запуск: первый список только запоминается, непрочитанного нет.
- Порядок строк строит закреплённое множество непрочитанных: оно обновляется только когда появляется новое непрочитанное, и в документ не пишется.
