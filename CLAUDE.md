# roost

Десктопное приложение для macOS и Linux над фоновыми сессиями агентов: само находит все сессии, группирует их, показывает родной TUI агента в терминальной панели и управляется с клавиатуры. Наследник прежнего Python TUI. Стек — Qt Quick и C++, эмулятор терминала — libghostty-vt.

## Работа по этапам — главное правило

Проект идёт этапами M0–M7. **После каждого этапа: показать результат, прогнать критерий готовности, показать его вывод — и остановиться.** Следующий этап не начинается без явной отмашки. Это касается и документов, и кода.

| Этап | Что |
|---|---|
| M0 | каркас: CMake с пресетами, Qt 6, сборка libghostty-vt, пустые `roost` и `roostd`, CI на macOS с гейтами format и tidy; Linux в CI — после решения, какой Linux |
| M1 | `roostd`: JSON-RPC на unix-сокете, шина событий, хранилище, загрузчик плагинов с бэкенд-процессами |
| M2 | PTY, тёплый пул `claude attach`, каналы сессий в протоколе, адаптер Claude: сессии из `claude agents --json`, состояния |
| M3 | терминал в окне: `TerminalSession`, поток ввода-вывода, рендер, `TerminalItem`, ввод и размер |
| M4 | окно: QML-плагины, список сессий (категории, пины, архив, непрочитанные), терминал. **Рабочий продукт: заменяет прежний TUI в ежедневной работе** |
| M5 | раскладка панелей со связями, keymap и палитра команд из вкладов плагинов |
| M6 | уведомления, PR по worktree, keep-awake |
| M7 | упаковка: `.dmg` и AppImage |

Шаги и критерий готовности каждого этапа — `docs/design/13-plan.md` (§13). После M7: адаптеры Codex и OpenCode, удалённый `roostd` через ssh, редактор связей, сторонний плагин как проверка API.

## Стек

- C++23, **только clang** (17+; на macOS — Apple clang из Xcode). Один компилятор — один набор диагностик.
- Qt 6, только модули под LGPLv3: Core, Gui, Qml, Quick, Quick Controls, Network, Test. Линковка динамическая. Модули только под GPL не подключать — список в `docs/design/10-licenses.md`.
- libghostty-vt — из исходников через CMake `FetchContent` на теге `vt-1.0.1`. Нужен Zig ≥ 0.17.0.
- Сборка только через пресеты: `cmake --preset dev`, `ctest --preset dev`. Пресеты: `dev`, `asan-ubsan`, `tsan`, `release`; санитайзеры гоняются в CI. TSan гоняется только ночью: `nightly-tsan.yml`, пресет `tsan-qt` с Qt под TSan, тесты с меткой `threads`; правила — `.claude/rules/threads.md`.
- Форматирование — `.clang-format` (google, 4 пробела) для C++, `qmlformat` для QML. Нейминг — `.clang-tidy`, `readability-identifier-naming`.
- Тесты: Qt Test для C++, Qt Quick Test для QML, `QT_QPA_PLATFORM=offscreen` (тестовые бинарники сами ставят его, если он не задан, так что прямой запуск тоже без окон). Тесты не трогают настоящий `~/.config/roost` и конфиги других программ.

## Нейминг

Два стиля: C++ — как в zet, QML и C++-слой, который видит QML, — как требует QML.

C++ (`.clang-tidy` в корне):

| Что | Как | Пример |
|---|---|---|
| классы, функции, методы | PascalCase | `SessionPool`, `ListSessions` |
| аргументы и переменные | camelCase | `sessionId` |
| глобальные константы, `static constexpr` члены | ALL_CAPS | `MAX_WARM_SESSIONS` |
| члены класса | PascalCase, приватные и защищённые с `_` | `Pty_`, публичный `Id` |
| перечисления | префикс `E` | `ESessionState`, значения `ESessionState::Blocked` |
| концепты | префикс `C` | `CAdapter` |
| параметры шаблонов | префикс `T` | `TValue` |
| пространства имён | lower_case | `roost` |
| файлы | snake_case | `session_pool.cpp` |

C++-слой для QML — `src/qml_api/`: типы с `QML_ELEMENT` и `QML_SINGLETON`, их `Q_PROPERTY`, сигналы и `Q_INVOKABLE`. Функции и методы там camelCase (`listSessions`, `titleChanged`), остальное как в C++ выше. Это задаёт `src/qml_api/.clang-tidy`; стиль берётся по месту объявления, так что заголовки слоя можно включать откуда угодно. Остальной C++ в QML напрямую не регистрируется.

QML (`qmllint`, `qmlformat`):

| Что | Как | Пример |
|---|---|---|
| файлы и компоненты | PascalCase | `SessionList.qml` |
| свойства, функции, сигналы, `id` | camelCase | `selectedSession`, `sessionOpened` |
| обработчики сигналов | `on` + имя с заглавной | `onSessionOpened` |
| перечисления и их значения | PascalCase | `SessionState.Blocked` |

## Чем roost не является

- Не терминал общего назначения — Ghostty, WezTerm и agterm лучше. Терминальная панель есть только для TUI агентов.
- Не IDE и не замена TUI агента — roost показывает родной TUI, а не свой чат поверх SDK.
- Не мультиплексор — сессии живут в самих агентах или в `roostd`, не в tmux.
- Не кроссплатформа в v1 — macOS и Linux. Windows не в планах.
- Не песочница — плагин видит всё, что видит API, включая транскрипты.

## Компоненты

- `roost` — окно на Qt Quick: оболочка, раскладка, панели плагинов, `TerminalItem`. Ядро терминала окна — `src/terminal/`.
- `roostd` — демон на QtCore и QtNetwork без GUI: адаптеры агентов, пул PTY, бэкенды плагинов, шина событий, хранилище. Переживает перезапуск окна.
- `plugins/` — встроенные плагины на том же API, что и сторонние.

Инвариант: **окно не держит состояния, которое нельзя восстановить из `roostd`.** Перезапуск окна не теряет ни сессию, ни вывод, ни раскладку.

## Референсы для сверки

Клоны изучённых проектов живут в скратчпаде сессии, а не в репозитории: `ghostty` (libghostty-vt, заголовки `include/ghostty/vt/`), `agterm`, `herdr`, `waveterm`, `Paradev`, `codex` (`codex-rs/app-server`). Коммиты — в шапке `docs/prior-art.md`. При новой сессии переклонировать при необходимости.
